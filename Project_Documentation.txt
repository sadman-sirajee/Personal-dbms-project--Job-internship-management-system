PROJECT TITLE:
Job/Internship Management System (CareerPulse Portal)

APPLICATION TYPE:
Web-Based Multi-Role CRUD Application with Role-Based Access Control (RBAC)

DEVELOPMENT STACK:
- Backend: PHP 8.2 (PDO MySQL)
- Database: MySQL 8.0 / MariaDB
- Frontend: HTML5, CSS3, Bootstrap 5.3, Bootstrap Icons
- Web Server: Apache 2.4 (XAMPP)
- Architecture: Role-Based Access Control (Admin vs Candidate/User)

--------------------------------------------------------------------------------
1. PROJECT OVERVIEW & SUMMARY
--------------------------------------------------------------------------------
The Job/Internship Management System is a full-featured web portal developed 
using PHP and MySQL with a strict separation between Administrator and Candidate 
(User) roles:

- ADMINISTRATOR: Holds full administrative privileges to manage all system users, 
  publish and update job/internship vacancies, view submitted candidate applications 
  across all postings, inspect applicant cover notes and portfolios, and update 
  application review statuses (Pending, Reviewed, Accepted, Rejected).
  
- CANDIDATE / USER: Has access to a dedicated candidate portal to explore vacancies, 
  filter by position type (Jobs / Internships), submit applications with contact 
  number, portfolio/resume links, and pitch notes, track review progress in real-time 
  via "My Applications", and withdraw pending submissions.

4. DATABASE DESIGN & TABLES
--------------------------------------------------------------------------------
Database: job_internship_db

Table: users
  id          INT AUTO_INCREMENT PRIMARY KEY
  name        VARCHAR(100) NOT NULL
  email       VARCHAR(100) NOT NULL UNIQUE
  password    VARCHAR(255) NOT NULL
  role        VARCHAR(20) DEFAULT 'User'
  created_at  TIMESTAMP DEFAULT CURRENT_TIMESTAMP

Table: jobs
  id           INT AUTO_INCREMENT PRIMARY KEY
  title        VARCHAR(150) NOT NULL
  company      VARCHAR(150) NOT NULL
  location     VARCHAR(100) DEFAULT NULL
  type         VARCHAR(20) NOT NULL (Job / Internship)
  description  TEXT
  deadline     DATE DEFAULT NULL
  created_at   TIMESTAMP DEFAULT CURRENT_TIMESTAMP

Table: applications
  id           INT AUTO_INCREMENT PRIMARY KEY
  user_id      INT NOT NULL (FK -> users.id ON DELETE CASCADE)
  job_id       INT NOT NULL (FK -> jobs.id ON DELETE CASCADE)
  phone        VARCHAR(50) DEFAULT NULL
  cover_note   TEXT DEFAULT NULL
  resume_url   VARCHAR(255) DEFAULT NULL
  status       ENUM('Pending', 'Reviewed', 'Accepted', 'Rejected') DEFAULT 'Pending'
  applied_at   TIMESTAMP DEFAULT CURRENT_TIMESTAMP
  UNIQUE KEY   unique_user_job (user_id, job_id)
